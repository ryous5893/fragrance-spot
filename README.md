# Fragrance Spot ｜ 香り診断

かわせみ祭 × 高崎モントレー（3F・4F）の香水自動販売機体験「Fragrance Spot」向け、
5問・約60秒のインタラクティブな香り診断サイト。

海外の高級フレグランスサイトを思わせる没入型の構成（Hero → スクロール3D → 診断 → 結果）で、
**外部画像を一切使わず**、全ビジュアルを SVG / CSS / Canvas でコード生成しています
（画像の読み込み失敗で崩れない・依存ライブラリなし・単一HTMLで動作）。

## ファイル

| ファイル | 内容 |
|---|---|
| `fragrance-spot.html` | メイン。5問診断＋スクロール3D＋香水ごとに世界観が変わる結果画面 |
| `scent-diagnosis.html` | 初期版。3問のシンプルな診断（仮名「香りA〜」） |

どちらも単一ファイル・依存なし。ブラウザで開くだけで動きます。

## 使い方（ローカル確認）

```bash
python3 -m http.server 8080
# → http://localhost:8080/fragrance-spot.html
```

`file://` で直接開いても動作します（診断・結果はJavaScriptで動作）。

## 内容の差し替え

`fragrance-spot.html` 内の `<script>` にある `CONFIG` だけを編集すれば変更できます
（HTML / CSS を触る必要はありません）。

- `scents` … 香り5本（名称・説明・ノート・タグ・配色）
- `codeMap` … 診断コード `AAA`〜`BBB`（Q1〜Q3）→ どの香りを出すか
- `prices` / `payment` / `location` / `surveyUrl` / `qrImage` / `howto`

Q4 は印象タグ、Q5 は結果のCTA文に反映されます。
診断ロジックは `runDiagnosisTests()` でチェックできます（ブラウザのコンソールに結果を表示）。

## 診断ロジック

- Q1〜Q3 の A/B で 8 タイプ（`AAA`〜`BBB`）を判定
- 8 タイプを 5 本の香りに割り当て（`CONFIG.codeMap`）
- Q4「印象」を結果文とタグに、Q5「目的」を結果の案内文に反映

## 注意

香り選びを楽しむための簡易診断です。医学的な診断ではありません。
香りは肌に直接つけず、試香紙でお試しください。
香り名・価格・設置場所・決済方法は変更になる場合があります。
